# Personal Expense Tracker

A desktop application built with C++ and Qt Widgets to help users manage and track their personal expenses.

## Features

- Add new expense records
- Edit and delete existing transactions
- Organize expenses by category
- Filter transactions by category
- Sort transactions, including by amount
- View total expenses and monthly spending
- Visualize spending with a donut chart
- Save expense records locally in a text file

## Technologies Used

- C++
- Qt Widgets
- Qt Creator

## Project Overview

This project was created to practice C++ programming and desktop application development. It combines a graphical user interface with basic expense management and local file storage.
